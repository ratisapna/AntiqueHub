# AntiqueHub

AntiqueHub is a full-stack eCommerce platform dedicated to buying and selling antiques. The website includes features like auctions, user profiles, cart, checkout, and order tracking.

## Features

- **Auction System**: Users can participate in auctions to buy rare antiques.
- **User Profiles**: Users can create profiles to manage their orders and personal information.
- **Cart & Checkout**: Simple cart system where users can add items, proceed to checkout, and purchase antiques.
- **Order Tracking**: Track the status of orders after purchase.

## Technologies Used

- **Frontend**: React,Tailwind
- **Backend**: Spring Boot (Java)
- **Database**: MySQL 
- **Version Control**: Git
